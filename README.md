# AI Campus Opportunity Agent

A beginner-friendly college project for discovering campus opportunities and supporting student career planning with AI.

## Project structure

- `frontend/` — React user interface, including reusable components, pages, assets, and frontend services.
- `backend/` — Flask API and its routes, controllers, data models, and configuration.
- `ai/` — Python modules for recommendations, career roadmaps, skill-gap analysis, and resume analysis.
- `database/` — MySQL schema and database setup notes.
- `docs/` — Project documentation and design notes.

## Team responsibilities

1. Member 1 — Frontend development (`frontend/`).
2. Member 2 — Backend and database development (`backend/`, `database/`).
3. Member 3 — AI development and integration (`ai/`).

## Getting started

The repository currently contains the initial structure and documentation. Add implementation and setup instructions as the team develops each part. Python dependencies are listed in `requirements.txt`.
