# Frontend

The React-based user interface for the AI Campus Opportunity Agent. Keep UI code under `src/`.

- `src/components/` — reusable interface pieces.
- `src/pages/` — page-level views and screens.
- `src/assets/` — images, icons, and other static assets.
- `src/services/` — frontend API calls and related service helpers.
